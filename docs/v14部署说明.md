# v14 部署说明 —— 多人登录版（一人一个账号）

> 更新包：`chaoxing-v14.zip`（全量包，可直接覆盖解压，**不会动 `data/` 数据目录**）
> 这一版把「访问码」换成了**真正的登录**：每人一个用户名 + 密码，
> 登录后只看到自己的任务、日志、绑定的学习通账号。账号由管理员在网页里开。
> 适用：你现在服务器是 v13，按下面 6 步升级。

---

## 这次改了什么

| 改动 | 说明 |
|------|------|
| **登录系统** | 用户名 + 密码登录，登录态存 HttpOnly Cookie（换设备要重新登录） |
| **首次初始化** | 第一次打开网站会引导你「创建管理员账号」，不用改任何配置 |
| **成员管理** | 管理员在「设置」页开号 / 改密 / 停用 / 删除，**支持批量添加** |
| **完全隔离** | 每人只看得到自己的任务、日志、绑定的学习通号；越权一律拒绝 |
| **改密码** | 成员可在「设置」页自己改密码 |
| **并发可配** | Worker 支持 `MAX_CONCURRENT`：有任务就自动开跑，最多同时 N 个 |
| 去掉 | 访问码（`OWNER_CODES`）机制整体移除，**起容器不用再加这个变量** |

**并发说明**：总并发 = 所有 worker 容器的 `MAX_CONCURRENT` 之和。
真正卡上限的是**服务器内存**和**超星风控**（上次整台服务器 IP 被封过），建议总量 **3~5**，别贪多。

cd /opt/chaoxing && tar czf ~/cx-data-$(date +%m%d).tar.gz data && ls -lh ~/cx-data-*.tar.gz

`chaoxing-web:latest`）原地保留**，随时能回退（见文末）。

## 部署步骤（在服务器上，6 步）

### 第 1 步：上传并解压

把 `chaoxing-v14.zip` 上传到 `/opt/chaoxing/`，然后：

```bash
cd /opt/chaoxing && unzip -o chaoxing-v14.zip
```

> 包里没有 `data/`，所以你的数据库、任务记录、账号都在，不会被覆盖。

### 第 2 步：自检（看数字，不要肉眼看中文）

```bash
cd /opt/chaoxing && echo "1=$(grep -c 'api/auth/login' web_panel.py) 2=$(grep -c 'admin/users' web_panel.py) 3=$(test -f auth.py && echo 1 || echo 0) 4=$(grep -c MAX_CONCURRENT worker.py) 5=$(grep -c loginUser templates/index.html)"
```

期望：`1>=1`、`2>=4`、`3=1`、`4>=3`、`5>=1`。任一项不对就别往下做，先告诉我。

### 第 3 步：构建新镜像（用新标签，不覆盖旧镜像）

```bash
cd /opt/chaoxing && docker build -t chaoxing-web:v14 .
```

最后一行看到 `Successfully tagged chaoxing-web:v14` 即成功。

### 第 4 步：停掉旧容器

```bash
docker rm -f chaoxing-web chaoxing-worker-1 chaoxing-worker-2 chaoxing-worker-3
```

### 第 5 步：起新容器（Web 1 个 + Worker 1 个）

启动 Web：

```bash
docker run -d --name chaoxing-web -p 5000:5000 -v /opt/chaoxing/data:/app/data -e AUTO_RESUME=true --restart unless-stopped chaoxing-web:v14 python3 web_panel.py
```

启动 Worker（`MAX_CONCURRENT=5` = 最多 5 个人同时刷，可自己改）：

```bash
docker run -d --name chaoxing-worker -v /opt/chaoxing/data:/app/data -e AUTO_RESUME=true -e MAX_CONCURRENT=5 --restart unless-stopped chaoxing-web:v14 python3 worker.py
```

### 第 6 步：确认

```bash
docker ps --format "table {{.Names}}\t{{.Image}}\t{{.Status}}"
```

期望 2 行都 `Up`，IMAGE 都是 `chaoxing-web:v14`。再看 Worker：

```bash
docker logs --tail 5 chaoxing-worker
```

期望看到：`[Worker] 已启动 (PID: 1)，最多同时执行 5 个任务，等待任务... AUTO_RESUME=True`

## 第一次使用（在手机上）

1. 打开 `http://<你的服务器IP>:5000` → 会出现 **「首次使用 · 创建管理员」**
2. 填一个你自己的**用户名 + 密码**（至少 6 位）→ 点「创建并进入」
3. 进「设置」页 → **成员管理**：
   - 单个添加：成员用户名 + 初始密码 → 「添加成员」
   - 批量添加：每行一个「用户名 密码」，一次生成一批
4. 把**网址 + 用户名 + 密码**发给朋友
5. 每个人登录后，各自在「控制面板」绑定**自己的学习通账号**，再去「我的课程」选课开始刷

**管理员能做的事**（设置 → 成员管理）：改密、停用（登不上）、启用、删除（连带解绑）。
管理员自己不能被停用/删除。

## 注意（重要）

1. **升级后老记录会看不到**：以前的访问码身份（含那份共享的绑定）跟新账号对不上，
   每人**第一次要用自己的学习通账号重新绑定一次**，属正常现象，绑一次就好。
2. **换设备要重新登录**：登录态存在浏览器 Cookie 里，换手机/浏览器要重登。
3. **`data/secret.key` 别删**：它是登录令牌的签名密钥，删了所有人要重新登录（不会丢数据）。
4. **加人不用重启服务**：直接在网页「成员管理」里开号即可。
5. **想调整同时刷课人数**：改 `MAX_CONCURRENT`（删了 worker 容器重新 run 一次），或多个 worker 容器相加。

## 回退到 v13（如果 v14 有问题）

旧镜像 `chaoxing-web:latest` 没被覆盖，直接用它起容器即可：

```bash
docker rm -f chaoxing-web chaoxing-worker
```

```bash
docker run -d --name chaoxing-web -p 5000:5000 -v /opt/chaoxing/data:/app/data -e AUTO_RESUME=true --restart unless-stopped chaoxing-web:latest python3 web_panel.py
```

```bash
docker run -d --name chaoxing-worker -v /opt/chaoxing/data:/app/data -e AUTO_RESUME=true --restart unless-stopped chaoxing-web:latest python3 worker.py
```

> 注意：容器跑的是**镜像里**的代码，所以磁盘上的代码被 v14 覆盖了也不影响回退。
> 唯一要避免的是：回退之后不要再执行 `docker build -t chaoxing-web:latest .`（那会把 v14 代码打进旧标签）。

## 忘记管理员密码怎么办

先删容器，再用带 `PANEL_ADMIN_RESET=1` 的命令启动，它会把管理员密码重置成 `admin123456`；
登录后**立刻去设置页改掉**，下次启动把那个变量去掉：

```bash
docker rm -f chaoxing-web && docker run -d --name chaoxing-web -p 5000:5000 -v /opt/chaoxing/data:/app/data -e AUTO_RESUME=true -e PANEL_ADMIN_RESET=1 --restart unless-stopped chaoxing-web:v14 python3 web_panel.py
```

可调项（都是 `-e` 环境变量）：

| 变量 | 作用 |
|---|---|
| `PANEL_ADMIN_RESET=1` | 开启重置（必填） |
| `PANEL_ADMIN_USER=名字` | 要重置哪个管理员（默认 `admin`）。**该名字不存在时会直接创建一个** |
| `PANEL_ADMIN_PASSWORD=新密码` | 重置成什么密码（默认 `admin123456`） |

> 提醒：重置完成后**下次启动请去掉这些变量**，否则每次重启都会把密码重置回去。
