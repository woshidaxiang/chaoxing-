## ⚪ 历史归档（`archive/`）

这些文档写于早期版本，**里面的访问码机制、镜像标签、容器数量都已被 v14 取代**，
仅作为版本演进记录保留，**新部署不要照着做**。

| 文档 | 对应版本 |
| --- | --- |
| [archive/v13修复说明](archive/v13修复说明.md) | v13（并发「秒过」修复：每线程 Session 隔离） |
| [archive/v12部署说明](archive/v12部署说明.md) | v12（Cookie 按账号隔离） |
| [archive/服务器配置与部署完全指南](archive/服务器配置与部署完全指南.md) | 早期完整部署指南 |
| [archive/阿里云部署指南](archive/阿里云部署指南.md) | 早期阿里云部署指南 |

> ⚠️ 归档文档里可能提到 `docker compose up`、`chaoxing-web:latest` 等旧做法 ——
> 前者在旧版 compose + 新版 Docker 组合下会报错，后者会覆盖回退镜像。
> 新部署请一律照「小白部署教程」用 `docker build` + `docker run` 与**带版本号的镜像标签**。
