# 阿里云部署指南 · 超星刷课面板

> 专为阿里云用户编写。阿里云的控制台、安全组、远程连接方式和腾讯云都不一样，
> 这份文档全部按**阿里云的实际界面**来写，跟着做就行。

---

## 第 0 步：先确认你买的是哪种阿里云服务器

阿里云有两种常见的服务器，**操作方式不同**，先对号入座：

| 类型 | 全称 | 怎么判断 | 控制台入口 |
|------|------|---------|-----------|
| **A. 轻量应用服务器** | Simple Application Server | 价格便宜（¥50-70/月），套餐式，有"流量包"概念 | https://swas.console.aliyun.com |
| **B. ECS 云服务器** | Elastic Compute Service | 配置可自由组合，有"实例""安全组""弹性公网IP"等概念 | https://ecs.console.aliyun.com |

**快速判断方法：**
- 打开 https://console.aliyun.com → 左上角「产品与服务」→ 搜索"轻量"
  - 能找到「轻量应用服务器」并且里面有你的实例 → 你是 **A 类**
- 搜索"云服务器 ECS"里面有你的实例 → 你是 **B 类**
- 记不清？看你购买时的页面标题，或者订单里写的是哪个

> 不确定也没关系，下面 **A 类和 B 类我都写了**，找到对应章节照着做即可。

## 第一部分：找到你的服务器信息

无论哪种类型，你都需要先记下这几个信息：

| 信息 | 说明 | 去哪找 |
|------|------|--------|
| **公网 IP** | 形如 `47.98.123.456` | 服务器详情页 |
| **登录用户名** | Linux 一般是 `root` | 详情页或购买时设置 |
| **登录密码** | 你自己设的 | 购买时设的，忘了可重置 |

📝 **建议现在就把公网 IP 记在手机备忘录里。**

## 第二部分：★ 开放 5000 端口（最关键，不配手机连不上）

这是新手最容易漏的一步。阿里云**两种服务器的配置方式完全不同**，注意区分。

### 【A 类】轻量应用服务器 — 配置"防火墙"

1. 打开控制台 https://swas.console.aliyun.com
2. 在服务器列表里，**点击你的服务器名称**进入详情页
3. 左侧菜单或顶部标签找到「**防火墙**」，点击
4. 你会看到当前的规则列表（默认可能有 22、80、443）
5. 点「**添加规则**」按钮
6. 填写：

```
应用类型：   自定义
协议：       TCP
端口范围：   5000/5000        ← 注意阿里云是"起止范围"格式
备注：       刷课面板
```

7. 点「**确定**」

**成功后规则列表会多出一条：**
```
TCP | 5000/5000 | 0.0.0.0/0 | 允许
```

> 💡 阿里云轻量应用服务器的防火墙**默认只放行少数端口**，必须手动加 5000。

### 【B 类】ECS 云服务器 — 配置"安全组"

ECS 没有"防火墙"，用的是「**安全组**」。

1. 打开控制台 https://ecs.console.aliyun.com
2. 左侧菜单点「**实例与镜像**」→「**实例**」
3. 找到你的实例，**记住它的地域**（比如"华东1（杭州）"）
4. 点实例 ID 进入详情，或直接点右侧「**更多**」→「**网络和安全组**」→「**安全组配置**」
5. 点「**配置规则**」
6. 点「**手动添加**」（或"快速添加"，如果有"HTTP"之类的不适用，用"手动添加"）
7. 填写入方向规则：

```
授权策略：   允许
优先级：     1
协议类型：   自定义 TCP
端口范围：   5000/5000
授权对象：   0.0.0.0/0        ← 或填你自己的IP更安全
描述：       刷课面板
```

8. 点「**保存**」

**保存后，安全组入方向会多出一条：**
```
允许 | 1 | 自定义TCP | 5000/5000 | 0.0.0.0/0
```

> ⚠️ **ECS 常见坑**：
> - 修改安全组后可能需要**重启实例**才生效（一般不用，但遇到问题可以试试）
> - 如果实例**没有公网 IP**，需要先「绑定弹性公网 IP (EIP)」才能从外网访问
> - 检查实例的"网络类型"是"专有网络"，确保有公网出口

## 第三部分：连接服务器

阿里云有自己官方的网页终端「**Workbench**」，**对小白最友好，推荐用它**。

### 方式 A：阿里云 Workbench（官方网页终端，最推荐）

**优点**：不用装软件，浏览器直接操作，阿里云官方工具
**缺点**：关掉浏览器窗口会中断正在跑的命令（适合执行短命令）

**步骤：**

1. **【A 类轻量】** 控制台 → 点服务器名称 → 右上角「**远程连接**」按钮
   **【B 类 ECS】** 控制台 → 实例列表 → 找到实例 → 右侧「**远程连接**」
2. 弹窗选择「**Workbench**」（推荐）或「**VNC**」
3. 首次使用会提示：
   - 输入用户名：`root`
   - 输入密码：你设置的密码
   - 如果提示"未设置密码"，点「**重置实例密码**」设置一个（需要重启实例生效）
4. 连接成功后，出现黑色终端：

```
Welcome to Alibaba Cloud Elastic Compute Service !

[root@iZbp1xxxxxxx ~]#
```

最后那个 `#` 就是命令行提示符，可以敲命令了。

> 💡 **Workbench 还有文件上传功能**：界面上方有个「文件」图标，可以上传下载文件，比 FinalShell 还方便！

### 方式 B：手机 SSH App（推荐，随时随地）

1. 手机应用商店搜 **Termius** 或 **JuiceSSH**，安装
2. 新建连接：
   ```
   名称：     阿里云刷课
   Host：     47.98.xxx.xxx     ← 你的公网IP
   Port：     22
   用户名：    root
   密码：      你设的密码
   ```
3. 保存并连接，首次提示"信任主机"点 Yes

### 方式 C：电脑 SSH 软件（推荐传文件用）

用 **FinalShell**（免费，中文）：

1. 官网下载安装
2. 新建 SSH 连接，填 IP / 22 / root / 密码
3. 连接后，下半部分是终端，上半部分是文件管理器（可拖拽上传）

## 第四部分：上传项目文件

> 💡 **最省事的办法：上传一个压缩包，而不是 40 个文件！**
> 见下方「方式 D」。强烈推荐小白用这个，不用一个个选文件。

### 方式 D：★ 上传压缩包（最推荐，最简单）

**本地准备：**
1. 拿到 `chaoxing-部署包.zip`（已打好包，40 个文件全在里面）
2. 不用解压，直接上传这一个文件

**服务器操作：**

```bash
# 1. 先安装 unzip（阿里云 Ubuntu 默认没装，必须先做这步）
apt update && apt install -y unzip

# 2. 进入目标目录
cd /opt
mkdir -p chaoxing
cd chaoxing

# 3. 用 Workbench/FinalShell 把 chaoxing-部署包.zip 上传到 /opt/chaoxing/
#    ⚠️ 注意：要传进 chaoxing 目录里，不要传成 /opt/chaoxing-部署包.zip
#    如果不小心传到了 /opt/ 下，移进来即可：
#    mv /opt/chaoxing-部署包.zip .

# 4. 解压
unzip -o chaoxing-部署包.zip

# 5. 检查解压结果
ls
ls api/ templates/ resource/    # 确认子目录里有文件
```

解压后应该能看到 `Dockerfile`、`web_panel.py`、`worker.py`、`api/`、`templates/` 等文件。

**然后直接跳到第五部分部署即可。**

> **如果 `apt install unzip` 太慢或失败**，用系统自带的 Python 解压：
> ```bash
> cd /opt/chaoxing
> python3 -c "import zipfile; zipfile.ZipFile('chaoxing-部署包.zip').extractall('.')"
> ls
> ```
>
> **如果中文文件名乱码**，改用 Python 方式解压即可（Python 能正确处理中文）。

> ⚠️ 解压后可以把 zip 删掉，不影响使用：
> ```bash
> rm chaoxing-部署包.zip
> ```

### 方式 A：Workbench 上传（阿里云用户最方便）

**怎么全选文件？**
- **Windows 资源管理器**：打开 `chaoxing` 文件夹 → 按 **`Ctrl + A`** 全选
  - 或者：点第一个文件，按住 **`Shift`** 再点最后一个文件
  - 或者：按住 **`Ctrl`** 逐个点击要选的文件
- **Mac 访达**：按 **`Command + A`** 全选

**上传步骤：**

1. 用 Workbench 连上服务器
2. 在终端里创建目录：
   ```bash
   cd /opt
   mkdir -p chaoxing
   cd chaoxing
   ```
3. 点 Workbench 上方的「**文件**」按钮（或"上传文件"图标）
4. 选择本地 `chaoxing` 文件夹里的文件上传
   - ⚠️ **不要上传** `.venv` 和 `.git` 目录（没用且很大）
   - ⚠️ 注意：`api`、`templates`、`resource` 是**文件夹**，要确保里面的内容也一起传上去
5. 等待上传完成

> 💡 **Workbench 上传小技巧**：如果一次选不了太多文件，可以先把本地文件夹压缩成 zip 上传（见方式 D）。

### 方式 B：FinalShell 拖拽

1. 用 FinalShell 连上服务器
2. 终端里 `cd /opt && mkdir -p chaoxing && cd chaoxing`
3. 上半部分（文件管理器）进入 `/opt/chaoxing`
4. **本地**打开 `chaoxing` 文件夹 → **`Ctrl + A` 全选** → 拖到 FinalShell 上半部分
5. 等待传输完成

> 💡 FinalShell 里也能全选：在上半部分的**本地文件区**点一下，按 `Ctrl + A`。

### 方式 C：git 克隆

```bash
cd /opt
git clone <你的仓库地址> chaoxing
cd chaoxing
```

### 检查文件是否完整

```bash
cd /opt/chaoxing
for f in Dockerfile docker-compose.yml requirements.txt main.py web_panel.py worker.py db.py api templates resource config_template.ini; do
  [ -e "$f" ] && echo "✅ $f" || echo "❌ 缺失: $f"
done
```

全部显示 ✅ 才能继续。有任何 ❌ 就重新上传缺失的文件。

**重点检查子目录：**
```bash
ls api/          # 应该有一堆 .py 文件
ls templates/    # 应该有 index.html
ls resource/     # 应该有 font_map_table.json
```
如果某个目录是空的，说明**文件夹里的内容没传上去**（常见问题！），需要重新上传该目录。

## 第五部分：一键部署

```bash
cd /opt/chaoxing
bash deploy.sh
```

脚本会自动：
1. 检测并安装 Docker（没装的话）
2. 配置国内镜像加速
3. 检查文件完整性
4. 构建镜像 + 启动两个容器
5. 健康检查 + 打印访问地址

**首次约 5-10 分钟**，耐心等待。

### 手动部署（如果不想用脚本）

> ⚠️ **阿里云服务器装 Docker 的坑**：官方安装脚本会从 `download.docker.com` 下载，
> 国内经常连不上（报 `Connection reset by peer`）。**必须加 `--mirror Aliyun` 参数**。

```bash
# 1. 安装 Docker（关键：加 --mirror Aliyun 走阿里云镜像源）
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun

# 如果上面还是失败，用保底方案（从 Ubuntu 系统源装）
# sed -i 's/archive.ubuntu.com/mirrors.aliyun.com/g; s/security.ubuntu.com/mirrors.aliyun.com/g' /etc/apt/sources.list
# apt update && apt install -y docker.io docker-compose

# 2. 启动并设置开机自启
systemctl enable docker && systemctl start docker

# 3. 验证
docker --version

# 4. 配置阿里云镜像加速（阿里云服务器必做，不然拉镜像很慢）
mkdir -p /etc/docker
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://你的ID.mirror.aliyuncs.com",
    "https://docker.m.daocloud.io",
    "https://hub-mirror.c.163.com"
  ]
}
EOF
systemctl restart docker

# 5. 部署
cd /opt/chaoxing
docker compose up -d --build
```

> 💡 **获取阿里云专属镜像加速地址**：
> 阿里云控制台 → 搜索「容器镜像服务」→ 左侧「镜像工具」→「镜像加速器」
> 里面会给你一个专属地址，形如 `https://xxxx.mirror.aliyuncs.com`，填到上面的配置里，下载会快很多。

## 第七部分：阿里云特有注意事项

### 7.1 实例密码重置

忘了密码：
- **【轻量】** 控制台 → 服务器详情 → 「更多」→「重置密码」→ 关机 → 重置 → 开机
- **【ECS】** 控制台 → 实例 → 「更多」→「密码/密钥」→「重置实例密码」→ 需重启实例生效

### 7.2 公网 IP 与 EIP

- **【轻量】** 自带公网 IP，直接可用
- **【ECS】** 如果实例只有内网 IP，需要：
  1. 控制台 → 「弹性公网 IP」→ 申请一个 EIP
  2. 绑定到你的实例
  3. 或者购买时勾选"分配公网 IPv4 地址"

### 7.3 安全组 vs 防火墙

| 类型 | 叫什么 | 在哪配 |
|------|--------|--------|
| 轻量应用服务器 | 防火墙 | 服务器详情页 → 防火墙 |
| ECS | 安全组 | 实例 → 网络和安全组 → 安全组配置 |

**两者都要放行 5000 端口。**

### 7.4 阿里云镜像加速（强烈建议）

阿里云服务器如果不配镜像加速，拉取 Docker 镜像可能非常慢甚至失败。
一定要用你的专属地址（见第五部分）。

### 7.5 快照备份

阿里云提供"快照"功能，可以给系统盘做备份：
- 控制台 → 实例 → 「快照」→ 创建快照
- 服务器出问题时可以回滚
- 建议在重要操作前做一次快照

### 7.6 费用与免费额度

- 新用户首年有折扣
- **学生优惠**：搜「飞天加速计划」，学生认证后可领免费/超低价 ECS
- 轻量应用服务器常有"新用户专享"活动价
- 用完记得 `docker compose stop` 省资源（但服务器费用照收，因为是包月的）

## 第十部分：故障排查（阿里云版）

### ❓ 手机打不开网页

**阿里云用户排查顺序：**

1. **端口有没有放行**（最常见）
   - 轻量：服务器详情 → 防火墙 → 有没有 TCP 5000/5000
   - ECS：实例 → 安全组 → 入方向 → 有没有 5000/5000
2. **ECS 有没有公网 IP**
   - 只有内网 IP 的话，外网访问不了，需要绑定 EIP
3. **服务是否在跑**
   ```bash
   cd /opt/chaoxing && docker compose ps
   ```
4. **本地能否访问**
   ```bash
   curl http://127.0.0.1:5000/healthz
   ```
   - 有返回 = 服务正常，问题在安全组/防火墙
   - 无返回 = 服务有问题，看日志
5. **地址格式**：`http://` 不是 `https://`，端口 `:5000`

### ❓ 构建时下载超慢 / 失败

阿里云必须配镜像加速（见 7.4），用你的专属地址。配置后：
```bash
systemctl restart docker
cd /opt/chaoxing && docker compose up -d --build
```

### ❓ Workbench 连接提示"未设置密码"

点「重置实例密码」，设置后**需要重启实例**才生效（控制台里可以重启）。

### ❓ 提示 "docker: command not found"

```bash
curl -fsSL https://get.docker.com | bash
```

### ❓ 容器一直 Restarting

```bash
docker compose logs --tail=50 chaoxing-web
```
常见原因：端口被占用、文件缺失、依赖安装失败。

### ❓ 登录失败 / 账号冻结

- 先在手机学习通 App 登录一次（阿里云地域可能触发异地登录风控）
- 提示"账号已冻结"：等 15 分钟
- 多次输错会触发风控，确认密码正确再试
