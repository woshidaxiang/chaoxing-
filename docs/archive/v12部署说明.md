# v12 修复版部署说明

## 这次修了什么

### 1. 核心修复：`Cannot get uid !` 崩溃

**现象**：刷视频时脚本报错退出，日志里全是

```
File "/app/api/base.py", line 491, in get_uid
    raise ValueError("Cannot get uid !")
```

**根因**：你有 3 个 Worker 容器并发跑**不同账号**的任务，但所有账号**共用同一个
`cookies.txt` 文件**。谁最后登录谁覆盖，导致另一个账号去上报视频进度时，
读到的 Cookie 是别人的 → 自己账号的 `_uid` 没了 → 直接抛异常。

**修复**：Cookie 改为**按账号隔离存放**。

- 改动文件：`api/cookies.py`、`api/base.py`
- 效果：账号 A 写 `cookies.<哈希A>.txt`，账号 B 写 `cookies.<哈希B>.txt`，互不干扰
- 文件名用哈希，不会把你的手机号暴露在文件名里

### 2. 增强：`get_uid` 三级兜底

拿不到 `_uid` 时不再立刻崩溃，而是依次尝试：

1. 从**持久化 Cookie 文件**里找（多账号隔离后读自己那份）
2. 请求**账号管理页**，从返回内容里抠 uid
3. 都失败才报错，且错误信息改成**能直接定位问题**的话术

### 3. 增强：单个任务点出错不再拖垮整个任务

**原来的问题**：`main.py` 里 `process_chapter` 一旦抛异常，整个 `worker_thread`
线程直接死掉。结果就是——**一个任务点失败，后面所有任务点全部不执行**，
任务永远卡在 running 状态。

**修复**：加了兜底捕获，单个任务点出错只标记该点失败，**继续跑下一个**。

## 部署步骤

### 第 1 步：上传并解压

把 `chaoxing-v12.zip` 上传到服务器 `/opt/chaoxing/`，然后：

```bash
cd /opt/chaoxing
unzip -o chaoxing-v12.zip
```

### 第 2 步：确认关键修复已生效

```bash
cd /opt/chaoxing && \
echo "1. Cookie按账号隔离=$(grep -c 'set_current_account' api/cookies.py)" && \
echo "2. 登录时注入账号=$(grep -c 'set_current_account' api/base.py)" && \
echo "3. get_uid兜底=$(grep -c '兜底' api/base.py)" && \
echo "4. 线程异常兜底=$(grep -c '处理任务点异常' main.py)"
```

**期望输出**：`1>=1`、`2>=1`、`3>=3`、`4=1`

### 第 3 步：重建镜像

```bash
cd /opt/chaoxing
docker build -t chaoxing-web:latest .
```

等它跑完，最后一行应该是 `Successfully tagged chaoxing-web:latest`。

### 第 4 步：重启全部容器

```bash
cd /opt/chaoxing
docker rm -f chaoxing-web chaoxing-worker-1 chaoxing-worker-2 chaoxing-worker-3 2>/dev/null

docker run -d --name chaoxing-web \
  -p 5000:5000 \
  -v /opt/chaoxing/data:/app/data \
  -e AUTO_RESUME=true \
  --restart unless-stopped \
  chaoxing-web:latest python3 web_panel.py

docker run -d --name chaoxing-worker-1 \
  -v /opt/chaoxing/data:/app/data \
  -e AUTO_RESUME=true \
  --restart unless-stopped \
  chaoxing-web:latest python3 worker.py

docker run -d --name chaoxing-worker-2 \
  -v /opt/chaoxing/data:/app/data \
  -e AUTO_RESUME=true \
  --restart unless-stopped \
  chaoxing-web:latest python3 worker.py

docker run -d --name chaoxing-worker-3 \
  -v /opt/chaoxing/data:/app/data \
  -e AUTO_RESUME=true \
  --restart unless-stopped \
  chaoxing-web:latest python3 worker.py
```

### 第 5 步：确认 4 个容器都起来了

```bash
docker ps --format "table {{.Names}}\t{{.Command}}\t{{.Status}}"
```

**期望**：4 行，全部 `Up`，COMMAND 分别是 `python3 web_panel.py` 和
`python3 worker.py`（3 个）。

## 验证方法

1. 手机无痕模式打开 `http://<你的服务器IP>:5000`
2. **重新登录**每个账号（重要！Cookie 隔离后需要重新写一次）
3. 分别给 2~3 个账号创建任务并开始
4. 观察日志，**不应该再出现** `Cannot get uid !`

如果想确认隔离文件已生成：

```bash
ls -la /opt/chaoxing/data/ | grep cookies
```

**期望**：每个账号一个 `cookies.<哈希>.txt` 文件。

## 排查命令

看某个 Worker 在跑什么：

```bash
for c in chaoxing-worker-1 chaoxing-worker-2 chaoxing-worker-3; do
  echo "===== $c ====="
  docker logs --tail 15 $c 2>&1
done
```

看数据库里最新日志：

```bash
docker exec chaoxing-web python3 -c "
import sqlite3
db = sqlite3.connect('/app/data/chaoxing.db')
db.row_factory = sqlite3.Row
for r in db.execute('SELECT message FROM logs ORDER BY id DESC LIMIT 40').fetchall():
    print(r['message'])
"
```

看任务状态：

```bash
docker exec chaoxing-web python3 -c "
import sqlite3, time
db = sqlite3.connect('/app/data/chaoxing.db')
db.row_factory = sqlite3.Row
for r in db.execute('SELECT id, owner, status, heartbeat FROM tasks ORDER BY id DESC LIMIT 8').fetchall():
    hb = r['heartbeat'] or 0
    ago = int(time.time()-hb) if hb else -1
    print(f\"任务{r['id']} [{r['owner']}] {r['status']} 心跳{ago}秒前\")
"
```
