## 一、先理解这套方案

在动手之前，先花 2 分钟搞懂它在干什么，后面就不会晕。

```
┌─────────────────────────────────────────────────────────┐
│                    云服务器（24小时开机）                  │
│                                                         │
│   ┌───────────────┐         ┌────────────────────┐      │
│   │  Web 面板      │         │   Worker 进程       │      │
│   │  （网页界面）   │         │   （真正干活的）     │      │
│   │               │         │                    │      │
│   │  · 输入账号    │         │  · 执行刷课脚本      │      │
│   │  · 选择课程    │         │  · 不受网页影响      │      │
│   │  · 查看日志    │         │  · 关手机也继续跑    │      │
│   └───────┬───────┘         └─────────┬──────────┘      │
│           │                           │                 │
│           └──────────┬────────────────┘                 │
│                      ▼                                  │
│           ┌─────────────────────┐                       │
│           │  SQLite 数据库       │                       │
│           │  记住任务和日志       │                       │
│           └─────────────────────┘                       │
└─────────────────────────────────────────────────────────┘
              ▲
              │ 手机浏览器访问 http://服务器IP:5000
              │
        ┌─────┴─────┐
        │  你的手机  │  ← 想看就看，想关就关
        └───────────┘
```

**三个关键点：**

| 问题 | 答案 |
|------|------|
| 手机要一直开着吗？ | **不用**。任务在服务器上跑，手机只是个遥控器 |
| 关掉网页会中断吗？ | **不会**。任务由独立的 Worker 进程执行 |
| 下次打开还能看到吗？ | **能**。所有状态和日志都存进了数据库 |

## 二、购买服务器（超详细）

### 2.1 为什么推荐腾讯云？

- 控制台界面最友好，中文文档全
- 轻量应用服务器比云服务器（CVM）简单，自带防火墙面板
- 学生认证后非常便宜（¥10/月）

其他可选：阿里云轻量、华为云、UCloud、或者任何 VPS。

### 2.2 需要买什么配置？

| 配置项 | 推荐值 | 为什么 |
|--------|--------|--------|
| CPU/内存 | **2核 2G** | 刷课脚本很轻，最低配足够 |
| 系统盘 | 40GB 起 | 数据库和日志很小，够用很久 |
| 带宽 | **4Mbps** 或以上 | 手机只是看网页，4M 足够 |
| 地域 | 广州/上海/北京 | 选离你近的，访问快 |
| 镜像 | **Ubuntu Server 22.04 LTS** | 教程最多，兼容性最好 |
| 时长 | 先买 1 个月试 | 好用再续年付 |

> 💡 **不要买**：Windows 系统（贵且没必要）、1核1G（勉强能用但容易卡）、共享型（性能不稳定）。

### 2.3 购买步骤（腾讯云为例）

**第 1 步：注册账号**
1. 浏览器打开 https://cloud.tencent.com
2. 右上角「注册」，用微信/QQ/手机号注册
3. 完成**实名认证**（个人认证，上传身份证，几分钟通过）
   - ⚠️ 不实名认证无法购买服务器

**第 2 步：进入轻量服务器购买页**
1. 打开 https://cloud.tencent.com/product/lighthouse
2. 点页面上的「**立即选购**」或「立即购买」

**第 3 步：选择配置**（这一步最关键）

页面上会看到这样的选项：

```
地域：        [广州 ▼]        ← 选离你近的
镜像：        [应用镜像] [系统镜像] [自定义镜像]  ← 选【系统镜像】
              [Ubuntu] [CentOS] [Debian] ...    ← 选 Ubuntu
              版本：[Ubuntu Server 22.04 LTS 64bit ▼]
实例套餐：    [2核2G4M]       ← 选这个（注意看月流量，一般够用）
              系统盘：40GB SSD
购买时长：    [1个月 ▼]        ← 先买1个月
数量：        1
```

**第 4 步：设置登录密码**
- 页面上会有「登录方式」或「设置密码」的选项
- 选「**自定义密码**」
- 设置一个密码，要求：**至少 8 位，包含大小写字母和数字**
- 📝 **务必记下这个密码**，后面连接服务器要用
  - 建议记在手机备忘录里，格式如：`腾讯云服务器 root密码：Abc123456`

**第 5 步：付款**
1. 勾选同意协议
2. 点「立即购买」或「提交订单」
3. 微信/支付宝付款
4. 付款成功后，会跳转到「**轻量应用服务器控制台**」

**第 6 步：记下服务器信息**

在控制台里，找到你刚买的服务器，会看到：

```
实例名称：   lighthouse-xxxx
实例ID：     lhins-xxxxxxxx
公网IP：     43.136.xxx.xxx      ← ★★★ 这个最重要，记下来！
内网IP：     10.0.0.xxx
状态：       运行中
地域：       广州
```

📝 **把公网 IP 记在备忘录里**，比如：`服务器IP：43.136.123.456`

> 如果控制台没显示公网IP，点一下服务器名字进详情页就能看到。

## 三、服务器初始化设置

服务器买好后，还需要做几件事。

### 3.1 进入服务器详情页

1. 在轻量应用服务器控制台，**点击你的服务器名称**
2. 进入详情页，会看到几个标签：`概要` `域名` `防火墙` `快照` `密钥` ...

### 3.2 ★★★ 配置防火墙（最重要，不配手机就连不上）

这是**新手最容易漏掉的一步**，漏了就会遇到"手机打不开网页"。

**操作步骤：**

1. 在服务器详情页，点「**防火墙**」标签
2. 你会看到当前的规则列表（默认可能有 22、80、443 等）
3. 点「**添加规则**」按钮
4. 弹窗里填写：

```
应用类型：  自定义
协议：      TCP          ← 选 TCP
端口：      5000         ← 填 5000
来源：      0.0.0.0/0    ← 允许所有IP（或者填你自己的IP更安全）
策略：      允许
备注：      刷课面板      ← 可选
```

5. 点「**确定**」

**添加后，规则列表里应该能看到一条：**
```
TCP | 5000 | 0.0.0.0/0 | 允许
```

> 💡 **更安全的做法**：来源不填 `0.0.0.0/0`，而是填你自己的 IP。
> 手机查自己 IP：浏览器搜「我的IP」，把显示的公网 IP 填进去（格式如 `123.45.67.89`）。
> 缺点是换了网络（比如从 WiFi 切到 4G）就要改，麻烦。小白建议先用 `0.0.0.0/0`。

### 3.3 确认服务器已启动

详情页顶部应该显示：
```
状态：● 运行中
```

如果是「已关机」，点「开机」。

### 3.4 记下登录信息

准备好这三样，下一步连接要用：

| 信息 | 值 | 从哪来 |
|------|-----|--------|
| 公网 IP | 43.136.xxx.xxx | 控制台首页 |
| 用户名 | `root` | 固定是 root |
| 密码 | 你设置的密码 | 购买时设置的 |

> 如果忘记密码了：详情页 → 「更多操作」→「重置密码」→ 关机重置 → 再开机。

## 四、连接服务器（3 种方式）

服务器就是一台远程电脑，你要"连上去"才能操作。下面三种方式，**选一种就行**。

### 方式 A：网页终端（最简单，推荐第一次用）

**优点**：不用装任何软件，浏览器里直接操作
**缺点**：不方便传文件，功能少

**步骤：**

1. 腾讯云控制台 → 轻量应用服务器 → 点你的服务器
2. 右上角找到「**登录**」按钮，点击
3. 弹出窗口，选择「**标准登录方式**」或「**VNC登录**」
4. 输入密码（购买时设的），回车
5. 看到这样的界面就成功了：

```
Welcome to Ubuntu 22.04.3 LTS (GNU/Linux 5.15.0-91-generic x86_64)

root@VM-4-13-ubuntu:~#
```

最后那个 `#` 就是命令行提示符，可以在后面输入命令了。

> ⚠️ 网页终端有个缺点：**关掉浏览器窗口，正在运行的命令会被中断**。所以它只适合执行短命令。长时间操作建议用方式 B 或 C。

### 方式 B：手机 SSH App（推荐，以后用手机管服务器）

**优点**：手机上就能管服务器，随时随地
**缺点**：手机上敲命令不太方便（但复制粘贴没问题）

**步骤（以 Termius 为例）：**

1. 手机应用商店搜 **Termius**（或 JuiceSSH），安装
2. 打开 App，点「**+**」新建连接
3. 填写：
   ```
   Alias（别名）：  我的刷课服务器      ← 随便起
   Host（主机）：   43.136.xxx.xxx     ← 你的公网IP
   Port（端口）：   22
   Username（用户名）：root
   Password（密码）：你设的密码
   ```
4. 点「Save」保存，然后点这个连接
5. 首次连接会提示「是否信任此主机」，点「**Yes / 接受**」
6. 看到 `root@VM-xxx:~#` 就成功了

### 方式 C：电脑 SSH 软件（推荐，操作最舒服）

**优点**：界面友好，方便传文件（拖拽上传）
**缺点**：要在电脑上操作

**步骤（以 FinalShell 为例）：**

1. 电脑搜索「FinalShell 下载」，去官网下载安装（免费）
2. 打开 FinalShell，点左上角「**文件夹图标**」→「**新建连接**」→「**SSH连接**」
3. 填写：
   ```
   名称：      我的刷课服务器
   主机：      43.136.xxx.xxx
   端口：      22
   用户名：    root
   密码：      你设的密码
   ```
4. 点「确定」，然后双击这个连接
5. 首次连接弹「未知主机密钥」，点「**接受并保存**」
6. 连接成功后，下半部分是**终端**（敲命令），上半部分是**文件管理**（拖拽传文件）

> FinalShell 还能实时显示 CPU、内存、网速，很方便。

## 五、上传项目文件

现在要把本地的 `chaoxing` 项目文件夹传到服务器上。

### 方式 A：用 FinalShell 拖拽（推荐小白）

1. 用 FinalShell 连接服务器（见方式 C）
2. 下半部分终端里输入：
   ```bash
   cd /opt
   mkdir -p chaoxing
   cd chaoxing
   ```
3. 上半部分文件管理器，进入 `/opt/chaoxing` 目录
4. 在**本地电脑**打开 `chaoxing` 文件夹，**全选所有文件**
5. 拖到 FinalShell 上半部分的 `/opt/chaoxing` 里
6. 等待上传完成（几秒到几十秒）

> ⚠️ **不要上传** `.venv` 和 `.git` 文件夹（没用且很大）。
> 如果全选时包含了，可以在服务器上删掉：
> ```bash
> cd /opt/chaoxing
> rm -rf .venv .git
> ```

### 方式 B：用 git 克隆（如果代码在 GitHub）

```bash
cd /opt
git clone <你的仓库地址> chaoxing
cd chaoxing
```

> 如果没有仓库，可以先把项目 push 到自己的 GitHub 私有仓库（注意别把 `data/` 传上去）。

### 方式 C：用 scp 命令（电脑命令行）

在**本地电脑**的终端里执行：

```bash
# Windows PowerShell / Mac 终端
scp -r "本地chaoxing文件夹路径" root@43.136.xxx.xxx:/opt/chaoxing
```

### 5.1 确认文件上传完整

上传后，在服务器终端执行：

```bash
cd /opt/chaoxing
ls
```

**应该看到这些文件：**

```
Dockerfile          deploy.sh           templates/
LICENSE             docker-compose.yml  tests/
README.md           main.py             web_panel.py
api/                pyproject.toml      worker.py
app.py              requirements.txt    db.py
config_template.ini resource/           小白部署教程.md
data/               start.sh            架构说明.md
                    stop.sh
```

**关键文件清单**（少一个都不行）：

| 文件/目录 | 作用 |
|-----------|------|
| `web_panel.py` | 网页后端 |
| `worker.py` | 任务执行进程 |
| `db.py` | 数据库 |
| `main.py` | 刷课主脚本 |
| `api/` | 刷课功能模块 |
| `templates/index.html` | 网页界面 |
| `resource/` | 字体资源 |
| `Dockerfile` | 镜像构建 |
| `docker-compose.yml` | 容器编排 |
| `requirements.txt` | 依赖清单 |
| `config_template.ini` | 配置模板 |

检查命令（一条命令列出缺失的文件）：
```bash
cd /opt/chaoxing
for f in Dockerfile docker-compose.yml requirements.txt main.py web_panel.py worker.py db.py api templates resource config_template.ini; do
  [ -e "$f" ] && echo "✅ $f" || echo "❌ 缺失: $f"
done
```

## 八、手机使用教程

### 8.1 首次使用

1. 手机浏览器打开 `http://你的IP:5000`
2. 在「账号登录」区域输入：
   - **手机号**：学习通绑定的手机号
   - **密码**：学习通登录密码
3. 点「**登录并获取课程**」
4. 稍等 3-10 秒，下方会出现你的课程列表

### 8.2 选择课程并开始

1. 课程列表出现后，**点击课程卡片**选中（选中会变蓝打勾）
   - 点「全选」可以一次选所有课程
2. 在「运行设置」里调整（新手用默认即可）：
   - **视频倍速**：建议 `1.0x`（最安全，不容易被检测）
   - **并发章节数**：默认 `4`
   - **关闭章节处理**：默认「重试」
3. 点底部绿色的「**▶ 开始刷课**」

### 8.3 查看进度

- 页面下方「**运行日志**」会实时滚动显示进度
- 顶部状态徽章会变成蓝色的「**运行中 ●**」
- 当前任务卡片显示「● 后台运行中」

### 8.4 ★ 关键：现在可以关掉浏览器了

任务在服务器上跑，**你关掉浏览器、关掉手机、关掉电脑都没关系**。

### 8.5 下次打开（状态恢复）

重新打开 `http://你的IP:5000`，你会看到：

- 顶部状态徽章显示当前任务状态
- 「当前任务」卡片显示任务 ID、账号、开始时间、日志条数
- 「运行日志」区自动加载**之前的所有日志**
- 页面底部「**任务历史**」列出所有历史任务，点任意一条可查看它的日志

### 8.6 停止任务

- 点底部的「**⏹ 停止**」按钮
- 或在「当前任务」卡片里点「⏹ 停止任务」
- 确认后任务会被终止，状态变为「已停止」

### 8.7 添加题库（可选，用于自动答题）

如果需要自动做章节测验，展开「🧠 题库配置」：

| 题库 | 需要什么 | 说明 |
|------|---------|------|
| 言溪题库 | Token | 需在 tk.enncy.cn 注册获取 |
| LIKE知识库 | Token | datam.site |
| AI大模型 | API地址+Key+模型 | 兼容 OpenAI 格式的任意 API |
| 硅基流动 | Key | siliconflow.cn |
| 手动输入 | 无 | 遇到题目时手动填答案 |

配置后勾选「自动提交答案」（注意：不保证正确率）。

### 8.8 添加到手机桌面（像 App 一样）

- **iPhone Safari**：点底部「分享」→「添加到主屏幕」
- **Android Chrome**：点右上角「⋮」→「添加到主屏幕」

之后点桌面图标就能直接打开，体验和 App 一样。

| 操作 | 命令 |

### 9.1 服务器重启后要做什么？

**什么都不用做**。容器配置了 `restart: unless-stopped`，服务器开机后 Docker 会自动把两个容器拉起来。

唯一要注意的是：如果重启时有任务在跑，任务会被中断，但因为开启了 `AUTO_RESUME=true`，Worker 会自动把中断的任务重新排队续跑（刷课脚本会跳过已完成的任务点，所以是安全的）。

### 9.2 更新代码后怎么部署？

```bash
cd /opt/chaoxing
# 上传新文件后
docker compose up -d --build
```

### 9.3 备份数据

```bash
cd /opt/chaoxing
tar czf ~/chaoxing-backup-$(date +%Y%m%d).tar.gz data/
```

然后用 FinalShell 把 `~/chaoxing-backup-*.tar.gz` 下载到本地。

## 十、安全加固

### 10.1 限制访问 IP（强烈建议）

面板本身没有登录密码，知道地址的人都能打开。最有效的防护是限制来源 IP：

1. 腾讯云控制台 → 服务器 → 防火墙
2. 找到 5000 端口那条规则，点「编辑」
3. 把「来源」从 `0.0.0.0/0` 改成**你自己的公网 IP**
   - 查自己 IP：手机浏览器搜「我的IP」
4. 保存

> 缺点：手机换网络（WiFi ↔ 4G）就要改。如果经常切换，可以用下面的方法。

### 10.2 改用非常规端口

把 5000 换成不常见的端口（如 38527），降低被扫到的概率：

```bash
cd /opt/chaoxing
nano docker-compose.yml
```

找到 `- "5000:5000"`，改成 `- "38527:5000"`，保存（`Ctrl+O` 回车，`Ctrl+X` 退出），然后：

```bash
docker compose up -d
```

记得在云控制台防火墙也放行 `38527` 端口。

### 10.3 用完就停

不用的时候停掉，最省心也最安全：

```bash
cd /opt/chaoxing
docker compose stop      # 停止
docker compose start     # 要用时再启动
```

### 10.4 保护账号密码

- `data/` 目录里有你的学习通账号密码，**绝对不要**分享或上传到 GitHub
- 项目自带的 `.gitignore` 已排除 `data/`，但如果你手动打包上传要注意
- 定期修改学习通密码

## 十一、故障排查大全

### ❓ 手机打不开网页

**排查顺序：**

1. **防火墙**（最常见）：控制台 → 防火墙 → 是否有 TCP 5000 且来源包含你 → 没有就加
2. **服务是否在跑**：
   ```bash
   cd /opt/chaoxing && docker compose ps
   ```
   两个都必须是 `Up`
3. **本地能否访问**（排除服务问题）：
   ```bash
   curl http://127.0.0.1:5000/healthz
   ```
   - 返回 JSON = 服务正常，问题在网络/防火墙
   - 连接失败 = 服务有问题，看日志
4. **地址格式**：必须是 `http://` 不是 `https://`，端口是 `:5000`
5. **IP 是否正确**：控制台确认公网 IP

### ❓ 提示 "docker: command not found"

Docker 没装好。重新执行：
```bash
curl -fsSL https://get.docker.com | bash
```

### ❓ 提示 "docker compose: command not found"

用带横杠的版本：
```bash
docker-compose up -d --build
```
或安装插件：
```bash
apt update && apt install -y docker-compose-plugin
```

### ❓ 构建时卡住 / 下载超时

配置镜像加速后重试：
```bash
mkdir -p /etc/docker
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.m.daocloud.io",
    "https://hub-mirror.c.163.com"
  ]
}
EOF
systemctl restart docker
cd /opt/chaoxing && docker compose up -d --build
```

### ❓ 容器状态是 Restarting / Exit

看日志找原因：
```bash
cd /opt/chaoxing
docker compose logs --tail=50 chaoxing-web
docker compose logs --tail=50 chaoxing-worker
```

常见原因：
- **端口被占用**：改 `docker-compose.yml` 里的端口
- **文件缺失**：用第五章的检查命令确认文件完整
- **依赖安装失败**：通常是网络问题，配镜像加速后重建

### ❓ 登录失败 / 密码错误

- 确认手机号密码正确（先用手机学习通 App 登录验证）
- 超星对异地登录敏感，**先在手机 App 上登录一次**，再回来试
- 提示「账号已冻结」= 多次输错被锁，等 15 分钟再试
- 需要图形验证码的账号：当前建议用 Cookie 登录

### ❓ 任务一直「等待 Worker 认领」

Worker 没起来：
```bash
docker compose ps                      # worker 是否 Up
docker compose logs chaoxing-worker    # 看报错
docker compose restart chaoxing-worker # 重启 worker
```

### ❓ 日志刷得很快但课程没进度

可能原因：
- 课程里都是**非任务点视频**，脚本会跳过（正常现象，观看时长不涨）
- 倍速设太高被限制，改成 1.0x 重试
- 账号在别处登录了，把服务器 session 顶掉了 → 手机别同时登学习通

### ❓ 想彻底重来

```bash
cd /opt/chaoxing
docker compose down          # 停止并删除容器
rm -rf data                  # 删除所有数据（谨慎！）
docker compose up -d --build # 重新部署
```

### ❓ 磁盘满了

```bash
df -h                          # 看磁盘使用
docker system prune -a         # 清理无用镜像和缓存
rm -rf /opt/chaoxing/data/logs/*   # 清理日志备份
```
